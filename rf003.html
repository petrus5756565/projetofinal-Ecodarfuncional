REQUISITO FUNCIONAL · RF003

Recuperar senha

O sistema permite que o usuário recupere o acesso à conta caso esqueça a senha, por meio de uma verificação segura.

Contexto

AtoresUsuário cadastrado
Pré-condiçãoTer uma conta cadastrada e acesso ao meio de recuperação associado a ela.

Entradas

  • E-mail cadastrado
  • Código ou link de recuperação
  • Nova senha e confirmação

Etapas do processo

  1. O usuário acessa a opção “Esqueci minha senha”.
  2. O sistema solicita o e-mail cadastrado.
  3. O usuário informa o e-mail.
  4. O sistema disponibiliza o procedimento de recuperação de forma segura.
  5. O usuário confirma sua identidade pelo método solicitado.
  6. O sistema apresenta o formulário para criação de uma nova senha.
  7. O usuário informa e confirma a nova senha.
  8. O sistema valida os dados e atualiza a senha.
  9. O sistema informa que a senha foi redefinida.

Saída

A senha é redefinida e o usuário pode voltar a acessar sua conta.

Regras de negócio

  • A recuperação deve utilizar um método seguro de verificação.
  • O código ou link de recuperação deve possuir prazo de validade.
  • A nova senha deve atender aos critérios de segurança.

Exceções

  • E-mail inválido: o sistema solicita sua correção.
  • Código inválido ou expirado: o sistema solicita uma nova recuperação.
  • Senhas diferentes: o sistema solicita a correção.
  • Falha no processo: a senha não é alterada.

RESUMO DO FLUXO

Recuperação verificada

A identidade é confirmada antes de a nova senha ser validada e registrada.
