REQUISITO FUNCIONAL · RF002

Fazer login

O sistema permite que usuários cadastrados acessem suas contas por meio de suas credenciais.

Contexto

AtoresUsuário cadastrado
Pré-condiçãoPossuir uma conta cadastrada.

Entradas

  • E-mail
  • Senha

Etapas do processo

  1. O usuário acessa a opção “Entrar”.
  2. O sistema apresenta o formulário de login.
  3. O usuário informa seu e-mail e senha.
  4. O sistema valida os dados informados.
  5. O sistema verifica as credenciais.
  6. O sistema autentica o usuário.
  7. O sistema direciona o usuário para a página inicial ou para a página que desejava acessar.

Saída

O usuário acessa sua conta e pode utilizar as funcionalidades que exigem autenticação.

Regras de negócio

  • As credenciais devem corresponder a uma conta cadastrada.
  • A senha deve ser verificada de forma segura.
  • O sistema deve proteger a conta contra tentativas excessivas de acesso indevido.

Exceções

  • Campos vazios: o sistema solicita o preenchimento.
  • Credenciais inválidas: o sistema informa que não foi possível realizar o login.
  • Falha de autenticação: o acesso não é concedido.

RESUMO DO FLUXO

Credenciais verificadas

Após validar e autenticar o usuário, o sistema libera as funcionalidades protegidas.
