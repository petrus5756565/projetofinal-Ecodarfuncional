REQUISITO FUNCIONAL · RF001

Fazer cadastro

O sistema permite que novos usuários criem uma conta para acessar as funcionalidades da plataforma e realizar compras.

Contexto

AtoresUsuário
Pré-condiçãoNão possuir conta cadastrada com o mesmo e-mail.

Entradas

  • Nome completo
  • E-mail
  • Senha e confirmação de senha
  • Data de nascimento, quando necessária
  • Demais informações solicitadas pelo sistema

Etapas do processo

  1. O usuário acessa a opção “Criar conta”.
  2. O sistema apresenta o formulário de cadastro.
  3. O usuário preenche os dados solicitados.
  4. O sistema valida os campos obrigatórios.
  5. O sistema verifica se o e-mail já está cadastrado.
  6. O sistema verifica se a senha atende aos critérios de segurança e corresponde à confirmação.
  7. O sistema registra a nova conta.
  8. O sistema informa que o cadastro foi realizado com sucesso.

Saída

Uma nova conta de usuário é criada e fica disponível para autenticação.

Regras de negócio

  • O e-mail deve possuir um formato válido.
  • O e-mail não pode estar associado a outra conta.
  • A senha deve atender aos critérios mínimos de segurança.
  • Todos os campos obrigatórios devem ser preenchidos.

Exceções

  • Campo obrigatório vazio: o sistema informa o usuário.
  • E-mail já cadastrado: o sistema impede o registro.
  • Senhas diferentes: o sistema solicita a correção.
  • Dados inválidos: o cadastro não é concluído.

RESUMO DO FLUXO

Da identificação à conta ativa

O sistema confere os dados antes de criar uma conta única e pronta para autenticação.
